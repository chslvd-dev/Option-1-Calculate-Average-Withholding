# Average Weekly Tax Withholding Calculator

This Java program calculates weekly tax withholding based on weekly income.

## Tax Rates

- Income below $500 uses 10%.
- Income from $500 through $1,499.99 uses 15%.
- Income from $1,500 through $2,499.99 uses 20%.
- Income of $2,500 or more uses 30%.

## Run the Program

Compile:

javac AverageWithholding.java

Run:

java AverageWithholding
